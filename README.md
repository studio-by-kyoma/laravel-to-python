# From Laravel to Python

Companion code for the blog series **From Laravel to Python** on Kyoma Journal.
Learning Python from the perspective of a PHP/Laravel developer. Every concept
is explained through comparison, so you build on what you already know instead
of starting from zero.

> Blog series: https://journal.kyomacorner.com/seri/dari-laravel-ke-python

## Who this is for

Developers who already write PHP and Laravel and want to pick up Python without
sitting through "what is a variable" all over again. If you know `echo`,
`$variable`, arrays, and OOP in PHP, you will feel at home fast.

## How it is organized

One folder per part. Each folder holds the code shown in that part of the blog.

```
part-01/   Your first Python program
part-02/   Variables and data types
part-03/   ...
```

## Running the code

Make sure Python 3 is installed, then run any file from its folder:

```
python part-01/halo.py
```
